# starqERP

This repository is the public, deliberately non-reconstructive product presence for starqERP.

The canonical product, its implementation, operational tooling, security design, tenant-isolation controls, data policies, and release history remain private. This repository is not a source mirror and must not be used to infer or recreate the proprietary product.

## Publication boundary

Public updates are prepared only as fresh stripped derivatives of an explicitly selected and verified private source commit. They are released after a publication-integrity and reconstruction review. There is no automatic private-to-public mirroring.

## Security reports

Please report security concerns to [security@starq.mv](mailto:security@starq.mv). See [the security policy](SECURITY.md).
